# 护肤图示说明

图1从屏障结构联系清洁、保湿、常见误区和生活选择；图2区分角质细胞、细胞间脂质、细胞内NMF、表面皮脂膜与正常TEWL；图3把常见误区与科学建议对应起来。

图1、图3及七张专题导图由程序排版，SVG保留可编辑中文文字。《角质层结构与水分流失》由AI辅助绘制，提供1672×941像素PNG；结构不按比例，箭头不表示流失量。

所有图示辅助理解机制。正常皮肤也有水分向外扩散；保湿不表示完全阻断TEWL，也不能由即时肤感判断屏障已修复。

lessons/内提供七个课堂专题的PNG、SVG和Mermaid；教师归属及材料范围见classroom_notes.md。scripts/build_figures.py只重建图1与图3，不覆盖新版图2。
