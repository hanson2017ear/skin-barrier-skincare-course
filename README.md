# 皮肤保健与美容课程笔记

[打开课程网页](https://hanson2017ear.github.io/skin-barrier-skincare-course/design-preview/)

中山大学公共选修课《皮肤保健与美容》的复习资料，包括七个专题的思维导图、屏障护理配图和六篇屏障护理相关文献，末讲另附两篇课件延伸阅读。

秋季课程 · 临床医学5班。仅供课程学习参考，不构成医疗建议。

## 课堂笔记

9月15日、22日为龚子鉴老师的课程，笔记分为皮肤基础、光电与注射美容、头发与护发三个专题；9月29日夏悦老师讲授常见损容性皮肤病；10月13日谢小元老师的课程对应抗老化专题；10月20日张云青老师讲授化妆品相关知识；10月27日许庆芳老师讲授面部色素性皮肤病，为最后一讲。共六次课，七个专题。
